# بيتنا POS

نسخة أولى لنظام سطح مكتب لمطعم أكل بيتي يعمل بالدليفري. الواجهة عربية بالكامل وتدعم:

- نقطة بيع منفصلة للأكل المطبوخ والأكل الطازة.
- سجل للعملاء وعناوين التوصيل.
- الدفع نقدي أو إنستاباي أو فودافون كاش.
- فصل حالة الطلب عن حالة التحصيل.
- فواتير معلقة مع الدليفري وتسويتها لاحقًا.
- شاشة تجميع أصناف للمطبخ.
- خزنة ومصروفات وحركات وردية.
- تقرير يومي ومبيعات حسب طريقة الدفع.
- حفظ محلي في SQLite عند تشغيل تطبيق Tauri.

## تشغيل الواجهة أثناء التطوير

```powershell
npm install
npm run dev
```

ثم افتح `http://localhost:1420`.

عند التشغيل في المتصفح تُحفظ بيانات التطوير في Local Storage. عند تشغيل نسخة سطح المكتب يستخدم التطبيق قاعدة SQLite باسم `beitna.db`.

## تشغيل نسخة سطح المكتب

يتطلب تثبيت Rust وMicrosoft C++ Build Tools وWebView2:

```powershell
npm run desktop:dev
```

## إنشاء ملف تثبيت Windows

```powershell
npm run desktop:build
```

ملف التثبيت الناتج يظهر داخل:

`src-tauri/target/release/bundle/nsis`
